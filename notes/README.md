# channel notes

a note here shows up on the site under that channel, in the drawer and on the channel's page.
are.na never sees these.

- one file per channel, `.md` or `.txt`
- name the file after the channel's title or its slug. `alt os.md`, `Alt OS.txt` and `alt-os-w7bwdpsnh4y.md` all work
- plain text. a blank line starts a new paragraph, and links are clickable
- channels without a file just don't show a note
